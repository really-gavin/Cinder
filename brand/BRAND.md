# Cinder brand

**Idea:** a cinder block is a block. Blocks get laid one at a time, in a wall,
each resting on the ones below. That's a blockchain. Everything else in the
brand comes from the building site: poured concrete, mortar lines, hi-vis
yellow, stencilled lettering.

## Mark
A cinder block seen face-on: one solid slab with two hollow cores.
`mark.svg` (hi-vis, for dark grounds) and `mark-ink.svg` (for light grounds).
Never outline it, rotate it, or put it in a circle. Minimum size 16 px wide.

## Name and units
- Name: **Cinder**. Ticker: **CDR**.
- Smallest unit: **ash** (1 CDR = 100,000,000 ash).
- Mining is finding blocks; the site calls it "laying" a block.

## Colour
| Token     | Hex       | Use                                   |
|-----------|-----------|---------------------------------------|
| Concrete  | `#d9d7d0` | Page ground (light)                   |
| Slab      | `#e9e7e1` | Raised surfaces, bricks               |
| Mortar    | `#b3afa4` | Lines and joints                      |
| Ink       | `#1f1e1b` | Text, the top bar                     |
| Dust      | `#6b675d` | Secondary text                        |
| Hi-vis    | `#f3d317` | The only accent. One thing per screen |

Night (dark mode): ground `#23221e`, slab `#2e2d28`, mortar `#4a4740`, ink `#ebe8df`.
Hi-vis stays the same. Never put hi-vis text on concrete: it's a fill, not a text colour.

## Type
- **Big Shoulders Stencil Display 800**: headlines, numbers, the wordmark.
  Big, tight, never for body text.
- **Archivo**: everything people read.
- **IBM Plex Mono**: hashes, addresses and keys only.
All three are free on Google Fonts.

## Voice
Plain and specific. Talk like someone who's actually run a node. No moon talk,
no promises about price, no rockets. "Every block laid by hand" is the line.
